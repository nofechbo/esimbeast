## FAQ Knowledge Base

Use the following Q&A pairs as your reference when answering customer questions. Adapt the answers to fit the conversation naturally — don't copy them verbatim.

---

**Q: Is my phone compatible with eSIM?**

Quick cheat sheet to check any phone:
1. Open your phone app.
2. Dial *#06#.
3. Look for an EID number.
   - If you see an EID number: your phone is eSIM compatible.
   - If you only see IMEI: it only supports physical SIM cards.

Important: Even if the phone is compatible, it must be **unlocked** to use a {{SITE_NAME}} eSIM. If they are still paying off their phone to a provider (like AT&T or Vodafone), the eSIM slot might be locked.

Full list of compatible devices: {{SITE_URL}}/info/supported-devices

---

**Q: When does the plan start?**

Data + validity only start when the customer first connects abroad (first signal overseas), unless the plan explicitly says otherwise. We recommend activating the eSIM before flying, from a place with a good internet connection.

---

**Q: Do I need Wi-Fi to install the eSIM?**

An internet connection is needed to download the eSIM profile. Wi-Fi is best. A stable mobile connection can work, but Wi-Fi is the safest bet.

---

**Q: Should I turn on Data Roaming for the eSIM?**

Yes. When arriving at the destination, Data Roaming must be ON for the {{SITE_NAME}} eSIM line, otherwise there may be no data.

---

**Q: How do I set the eSIM as Mobile Data (and keep my main SIM for calls)?**

iPhone (iOS):
Settings > Cellular/Mobile Data > Cellular Data > select {{SITE_NAME}} eSIM.
Keep Default Voice Line = main SIM.
We recommend not allowing data switching to avoid extra cost from the main SIM provider.

Android:
Settings > Network & Internet / SIMs > Mobile Data > select {{SITE_NAME}} eSIM.
Calls/SMS can stay on the main SIM.

---

**Q: Why don't I have internet?**

90% of the time it's one of these:

1. **Wrong line selected for Mobile Data** — Set {{SITE_NAME}} eSIM as Mobile Data.
2. **Data Roaming OFF** — Turn Data Roaming ON for the {{SITE_NAME}} eSIM.
3. **Not abroad yet** — Plans start when first connected overseas (data + validity start on first signal abroad, unless stated otherwise).
4. **APN needed (mostly Android)** — For some Android devices, APN is required for Turkey and Georgia. Use "isp" as the APN:
   - Settings > Connections > Mobile Networks > Access Point Names
   - Select the {{SITE_NAME}} eSIM, tap Add (+)
   - Name: {{SITE_NAME}}, APN: isp
   - Save, make sure the new APN is selected, then restart.
5. **Network coverage / operator issue** — Toggle Airplane mode, restart phone, or manually select another supported network.

**Q: Does the eSIM include calls/SMS or only data?**

Most {{SITE_NAME}} plans are data-only. Internet works, but no regular calls/SMS on the eSIM line. Customers can still use WhatsApp, iMessage, FaceTime, Telegram, etc. over data.

---

**Q: Can I keep WhatsApp / iMessage / FaceTime working?**

Yes. Keep the main SIM active for the phone number, and set {{SITE_NAME}} eSIM as Mobile Data. For iMessage/FaceTime: ensure the Apple ID/number stays selected in Settings > Messages / FaceTime.

Open the {{SITE_NAME}} activation email > tap Activate Now > then Check Usage. If the email can't be found, contact support via WhatsApp or {{SITE_EMAIL}}.

**Q: Can I hotspot / tether?**

Yes — all our eSIMs support hotspot/tethering.

---

**Q: Can I use it in multiple countries?**

If they bought a regional plan (e.g., Europe/Asia), yes. If it's a single-country plan, it works only in that country. Tip: if crossing borders, suggest a regional plan for seamless connectivity.

---

**Q: What happens if I delete the eSIM? Can I reinstall?**

eSIMs are one-time install. If deleted, reinstall is not possible. If troubleshooting, tell the customer to message us first — we'll fix it without deleting the eSIM.

---

**Q: Does it work on 5G?**

We do our best to provide 5G in all available areas. It also depends on whether the device supports 5G and whether the local operator provides it. If 5G isn't available, it falls back to 4G/LTE automatically.

---

Still nothing? Send the order number to support and we'll resend immediately.

**Q: Refund policy / it didn't work**

1. **"Zero Connection" Guarantee (Full Refund):** If unable to activate or get the eSIM to work despite following setup guides, we issue a 100% full refund. No hidden fees.
2. **"Fair Play" Network Policy (Partial Refund):** In the rare event of a network failure after the plan has been used, we may issue a partial refund for the data that wasn't used.

---

**Q: Security / privacy**

We only collect what's needed to deliver/support the eSIM (usually email + order details). Full privacy policy: {{SITE_URL}}/legal/privacy-policy

---

**Q: Missing eSIM delivery / didn't receive eSIM**

Contact support for an instant resend:
- WhatsApp (fastest)
- Email: {{SITE_EMAIL}}

Provide the Order Number or email and we'll resend the eSIM right away.

---

**Q: Fair Usage Policy (Unlimited Plans)**

Unlimited plans have a daily high-speed allowance (typically 5-10GB per 24h). After exceeding, speed reduces to ~512kbps until the next cycle. No extra charges. Heavy tethering at scale, P2P, automated downloads, and reselling are prohibited.
